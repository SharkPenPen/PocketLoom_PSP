### 下一步：平台导出（runtime + 打包器）

产品目标：编辑器直接导出可运行的平台包，不在编辑器里编译 C++。

架构：

1. CI 预生成并版本化 runtime 壳：
   - 3DS：ELF + SMDH + banner + RSF + makerom
   - PSP：EBOOT.BIN/PRX + PARAM.SFO + ISO 目录模板
2. 编辑器只做：
   - 导出 `game.p3d`
   - 写入项目元数据（标题、图标、唯一 ID、存档名）
   - 调用 makerom / ISO 打包器
3. 导出前校验 p3d 版本与 runtime 版本一致。

关键边界：

- 3DS CIA 是可安装的未签名 homebrew，不能生成任天堂签名 CIA。
- PSP ISO 是未加密 homebrew，PPSSPP/CFW 可跑，OFW 不行。
- 不把 devkitARM/pspdev 塞进编辑器；只带最终打包工具和 runtime 模板。
- PSP 先做 EBOOT/zip（PPSSPP/CFW），ISO 第二阶段。

预估（单人）：

- PSP EBOOT/zip 导出：3–5 天
- PSP 一键 ISO：再 5–7 天，总计约 1.5–2 周 MVP、2–3 周稳定
- 同时接 3DS CIA：再加 3–5 天

建议顺序：

1. runtime 壳版本化 + p3d 注入
2. PSP EBOOT/zip 输出
3. 项目元数据/图标/版本检查
4. PSP ISO
5. 3DS CIA 接入
6. PPSSPP/CFW/Azahar 实测
